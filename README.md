## Deskripsi Praktikum
Praktikum ini membahas tentang CSS Box Element, CSS Float Property, HTML5 Semantic Elements, serta pembuatan layout halaman web sederhana (Home, Artikel, About, dan Contact).

## Penjelasan File & Hasil Praktikum
- `lab4box.html`: Latihan konsep Box Element, Float, dan Clear.
- `lab4_layout/`: Folder berisi layout web utama beserta CSS-nya.
  - `index.html`: Halaman utama / Home.
  - `artikel.html`: Halaman artikel.
  - `about.html`: Halaman profil & portofolio.
  - `contact.html`: Halaman form kontak.
  - `style.css`: File stylesheet layout.
